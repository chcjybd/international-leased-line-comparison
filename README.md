# 国际专线申请：流程、资质与IEPL/IPLC/IX方案选型（含全套餐对比）

申请国际专线的第一步,不是比价格,而是先想清楚你要拿这条线做什么。如果只是临时翻墙看看网页,根本不需要专线;但只要业务涉及跨境电商后台、海外平台 API 调用、海外 SaaS 访问或者直播推流,普通家庭宽带和公网 VPS 的稳定性往往不够,这时候"国际专线"才会进入候选名单。

这篇文章会先把"国际专线"这个概念拆开讲清楚,然后梳理申请流程中真正会卡住人的合规与实名要求,最后把目前市场上比较活跃的几类专线交付形态(IEPL、IPLC、IX)放在一起对比,并以 Mkcloud 这家服务商的全套餐作为具体参考,帮助你直接落地选型。

## 国际专线到底是什么,跟普通宽带有什么区别

国际专线,是服务商把国内一个城市的机房和海外一个城市的机房,通过专线(租用运营商的跨境电路)直接打通的服务。它的核心特征有三个:

第一,**端到端路由固定**,不走公网骨干 BGP,不绕道。这跟普通家庭宽带"先看运营商,再看骨干网,再看对方国家"的随机路由完全不是一个东西。

第二,**带宽与延迟可控**。服务商在销售页写的"端内延迟 1~2ms""21ms""25~28ms",指的是服务商自家机房 A 端到 B 端的参考值,不是用户到目标网站的全程时延。但即便如此,它仍然比公网绕行稳定得多。

第三,**通常按专线 VPS 交付**。Mkcloud 这一类服务商把专线包成一台 VPS,每台机器分一个独立的入口 IP 和一个独立的出口 IP。用户连接入口,在 VPS 内运行业务,流量自动从出口 IP 发出去。这种交付方式的好处是免去了裸专线的开通、测试和对接环节,坏处是出口不接受外部连入,不能直接当公网服务器用。

需要强调的是,专线不等于"翻墙"。Mkcloud 在知识库中明确说明:出口只出不进,不支持外部连入;平台禁止机场、回国等违法违规用途。这是合规底线,也是申请前必须接受的限制。

## IEPL、IPLC、IX 三种交付方式分别适合谁

在跨境专线的语境下,IEPL、IPLC、IX 是最常碰到的三个名词,但很多人会把它们当成同义词。实际上它们指代不同类型的底层电路。

**IEPL**(International Ethernet Private Line)是以太网级别的专线,带宽颗粒度灵活,可以按 5Mbps、10Mbps、50Mbps 这种精细档位买,适合对持续速率有明确要求的业务。Mkcloud 的广港 IEPL、沪港 IPLC 独享、厦港专线等都属于这类,广港方向端内延迟可以做到 1~2ms。

**IPLC**(International Private Leased Circuit)是传统的点对点专线,通常按月租带宽计费。Mkcloud 的沪港 IPLC、沪日 IPLC、沪美 IPLC、港法 IPLC 都属于 IPLC 系列。沪港 IPLC 端内参考 21ms,沪日 IPLC 端内参考 25~28ms,沪美 IPLC 端内参考 124~134ms。

**IX**(Internet eXchange)是云厂前置接入的互联专线,本质上是把服务商的对等互联节点延伸到主流云厂商的内网里。好处是延迟极低(深港 IX 端内 1~2ms),但前提是你必须用支持范围内的云厂机器作为前置。深港 IX、沪日上云互联优化专线、沪港 IXP 都属于这类。

简单来说:**IEPL 偏持续速率,IPLC 偏按月包月,IX 偏云内互通**。如果业务跑在云上、追求最低延迟,选 IX;如果业务主要在本地、追求稳定速率,选 IEPL;如果是常规跨境办公/电商后台,IPLC 的性价比往往最高。

## 申请国际专线前必须搞清楚的合规与实名要求

国际专线的合规边界比普通 VPS 严格得多。Mkcloud 在隐私政策中写得很清楚,这里以它的要求为代表,几乎所有合规服务商都是类似标准:

**个人用户**需要提供手机号码、姓名和身份证号,依据是《网络安全法》第二十四条的实名认证要求。

**企业用户**需要提交企业名称、营业执照编号、法人身份证号以及对公银行账户,用于支付验证。

**业务用途限定**:平台明确禁止机场、回国等违法违规用途,仅限个人或企业正规用途。这意味着如果你想用它做"加速器""翻墙回国",不仅会被服务商拒绝,还可能因为违反《国际通信管理条例》和工信部规定而承担法律责任。

**数据出境**:如果是企业用户,业务数据涉及跨境传输,需要走国家网信办组织的安全评估或签订 SCC 标准合同条款。这部分由业务方自行负责,服务商只提供合规的物理通道。

> **合规提示**:跨境网络专线属于电信业务范畴,个人用户在国内无法直接向三大运营商申请"国际专线",合规渠道通常是通过持有相应授权的服务商(如 Mkcloud 这类)代为开通。

所以,申请之前先确认两件事:你的用途是否在平台允许范围内,以及你愿意提供企业或个人的实名材料。这两步不过,后面都白谈。

## 国际专线申请的完整流程(以 Mkcloud 为例)

下面这套流程是通用模板,绝大多数合规专线服务商都适用:

**第一步,选择方向与线路**。明确你的业务出口目标,是到香港、日本还是美国,以及国内入口适合用哪个省份的运营商。这一步决定了延迟和稳定性。

**第二步,选择共享或独享**。共享带宽是峰值,不保证持续跑满,价格低;独享带宽保证持续速率,价格高。短时上传或轻量后台选共享,持续推流或大数据同步选独享。

**第三步,估算月流量**。Mkcloud 的流量套餐按上行、下行双向统计,达到额度后暂停,可自助购买流量重置或补差价升级。如果用量不准,先用共享中间档跑一两个月再调整。

**第四步,注册账号并完成实名**。个人上传身份证正反面,企业上传营业执照和对公账户。审核通常 1 个工作日内完成。

**第五步,选择配置与计费周期**。Mkcloud 支持一次性支付、月付、季付、半年付、年付、两年付、三年付。周期越长单价越低,但需要一次性投入。

**第六步,付款开通**。Mkcloud 多数产品约 1 分钟自动开通;但库存、支付确认和系统安装可能影响时间。

**第七步,基础验收**。拿到入口 IP 后,先用 ping/mtr 看路由,再用 iperf3 在获授权的对端测试吞吐。Mkcloud 建议先做短时低负载验证,再做双方认可的压力测试;持续满载 48–72 小时可能消耗大量流量,不是默认动作。

## 不同出口方向怎么选:广港、沪港、沪日、沪美

方向选择是申请专线时最容易纠结的地方。Mkcloud 知识库给了一个简表,可以直接借用:

| 业务方向 | 推荐线路 | 端内参考延迟 | 适用场景 |
| --- | --- | --- | --- |
| 华南到香港 | 广港 IEPL | 1~2ms | 需要香港出口的华南团队 |
| 上海/长三角到香港 | 沪港 IPLC | 21ms | 上海入口、香港出口 |
| 日本方向 | 沪日 IPLC | 25~28ms | 日本平台访问和客户端测试 |
| 美国方向 | 沪美 IPLC | 124~134ms | 美国平台访问和素材传输 |

几个判断要点:

- **人在华南 + 业务出口是香港**,广港 IEPL 几乎是最优解,因为端内 1~2ms 比沪港 21ms 体感差异大。
- **人在上海/长三角 + 业务出口是日本/美国**,沪日/沪美 IPLC 是标配,延迟和带宽都能稳定支撑。
- **业务跑在阿里云、腾讯云、UCloud 上**,深港 IX 或沪港 IXP 的端内延迟和云内互通体验会更好。
- **业务面向欧洲**,港法 IPLC 是 Mkcloud 的专项产品,但 Mkcloud 明确说"具体套餐配置和价格官网会根据上架节奏调整",申请前需要直接到官网咨询。

注意:**表中延迟是端内参考值,不是用户到业务平台的全程测量**。如果你的业务对全程延迟敏感,应该用目标平台的实际访问测试来确认。

## 共享与独享、流量计费 vs 独享计费

很多人在选套餐时被"200Mbps 峰值""5Mbps 独享"这类参数绕晕。这里拆开讲:

**共享 + 流量计费**:带宽数字是峰值(共享池的上限),流量按双向使用量计费。适合访问频次高、单次传输小的业务,比如跨境电商后台、API 调用、海外 SaaS 访问。

**独享 + 不限流量**:带宽数字是保底速率,不与他人共享,流量通常不限(部分套餐设上限)。适合持续传输,比如直播推流、素材上传、批量数据同步。

以 Mkcloud 沪港入门套餐为例做对比:

- **共享版**:1 核 / 2GB / 20GB 硬盘 / 200Mbps 峰值 / 1024GB 月流量 / 月付 288 元。
- **独享版**:2 核 / 4GB / 40GB 硬盘 / 5Mbps 独享 / 不限流量 / 月付 388 元。

200Mbps 与 5Mbps 不是同一个量级的比较,前者是峰值上限,后者是保底速率。短时间上传可能更看重峰值,长时间传输更看重持续速率与额度。协议、磁盘、CPU 和对方限速都会影响实际速度。

**升降级通过工单操作**。套餐升级直接付款;降级至更低价格套餐时差价不退,是否迁移以工单处理结果为准。

## 几个常见问题的直接回答

**国际专线一个人能申请吗?**

可以。Mkcloud 接受个人实名,提供手机号、姓名和身份证号即可。但用途必须合规,平台禁止机场、翻墙回国等违规场景。

**怎么判断自己该选共享还是独享?**

业务以间歇访问、短时上传为主,选共享 + 流量计费;业务以持续传输为主,选独享 + 不限流量。

**独享套餐的"Mbps"和共享套餐的"Mbps 峰值"是一回事吗?**

不是。共享的 Mbps 是峰值上限,不保证持续跑满;独享的 Mbps 是保底速率,长期可达到。200Mbps 共享与 5Mbps 独享是两个完全不同口径的比较。

**广港、沪港、深港怎么选?**

入口运营商匹配 + 目标出口匹配。华南入口选广港,上海入口选沪港,云内业务选深港 IX。

**申请之后能不能换地域?**

Mkcloud 开通后不支持更换其他地域产品。申请前要确认入口省份、出口方向和带宽档位。

**套餐包含 DDoS 防护吗?**

普通 IEPL/IPLC 套餐默认不含高防;厦港专线默认含 100Gbps DDoS;广港大带宽独享自带 300G 高防。其他方向需要单独评估防护方案。
